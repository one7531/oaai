# Seedance 2.5：一支實拍變多機位

這是一份以真人手沖咖啡口播實測整理的繁體中文 Prompt 包。使用情境是：你已經拍好一支影片，希望用 Seedance 2.5 的影片編輯／全能參考，補出原本沒有拍到的攝影機角度。

這不是「按一下就能得到完美同步成片」的保證。實測最可靠的做法，是把 AI 輸出當作額外 coverage，最後沿用原始音軌，在剪輯軟體重新挑鏡頭與對動作。

## 最簡單的使用方式

1. 上傳 4–7 秒的原始實拍為 `@视频1`。
2. 若有明顯新側面角度，可加人物多角度設定表；若臉很重要，再加一張原片抽出的真人臉部幀。
3. 選一套 Prompt，依你的影片長度修改時間碼。
4. 生成後不要急著整段替換原片。逐顆檢查鏡頭、動作、嘴型、眼睛與器具。
5. 最後使用原始音軌，在剪輯軟體重新切點。

即夢裡的素材編號可能不是 `@视频1`、`@图片1`、`@图片2`，送出前要改成介面實際顯示的標籤。

## 實測最穩的鏡頭

- 從房間正上方 90° 鳥瞰，垂直下降到桌面。
- 壺嘴、水流、手部、V60 或其他物件的近距離特寫。
- 高位 over-the-shoulder，讓肩膀當前景、臉留在畫外。
- 地板貼地的房間廣角遠景。
- 從兩個前景物件之間 dolly-out，再 crane-up 展開空間。
- 從人物中景快速升高並拉遠，作為收尾。

## 很有趣，但要另外驗臉的鏡頭

- 椅背等大型失焦前景橫移後 reveal 人物。
- 24mm 地板低位弧形環繞。
- 容器內部向上看的圓形框景 probe-lens POV。
- 清楚看得到側臉的移動近景。

容器內 POV 曾在一次生成中成功保留可見的嘴部活動，也曾在另一次生成中整顆嘴巴幾乎不動。因此「構圖生得出來」和「嘴型同步」是兩件事，每次都要重新驗收。

## 不要再踩的雷

- 不要把「多機位」寫成整段一鏡到底的環繞運鏡。
- 不要只把正面中景換成另一個差不多的正面中景。
- 不要在 Prompt 寫原片沒有的動作，模型很可能真的讓人物重演。
- 不要相信指定的 1.0／2.0 秒一定會準時切；實測會提前、延後或壓縮其中一顆。
- 720P 只讓細節更清楚，不會自動修好眼睛、視線或嘴型。
- 人物設定表能補靜態角度，不能鎖逐格眨眼與 lip-sync。
- 不要只看單張截圖驗收嘴型；至少連續播放一次，再逐格看異常區間。

## 為什麼 Prompt 不再寫得超級長

實測後發現，真正需要反覆講清楚的是「影片是唯一動態依據」和「切換不同實體機位」。眼睛、嘴型、物件、光線等共同限制寫一次即可。每顆鏡頭的文字應該把注意力留給角度、焦段、距離、主要運鏡與前景關係。

只有當某一顆清楚看得到正在說話的臉，才在那一顆額外重申嘴唇、下巴、眨眼與視線要跟隨原片。
